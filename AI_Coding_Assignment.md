Artificial Intelligence – Group Coding Assignment 

Title: AI-Based Crop-Safe Path Planning for an Autonomous Potato-Field Robot

Language Python 

1. Background
An autonomous robot used for potato-field monitoring must travel between crop rows, visit selected monitoring locations and avoid damaging plants. It may also encounter obstacles such as stones, tools or other objects. In this assignment, you will model the field as a two-dimensional grid and use AI search techniques to plan a suitable route.

2. Problem Statement
Develop an intelligent path-planning agent that guides a robot from a specified starting position to a destination in a simulated potato field. The robot must avoid obstacles and crop-protection regions while selecting a route with a low overall movement cost. Your program should also demonstrate how the robot can update its knowledge of the field when it detects an obstacle that was not known in advance.

3. Tasks to be Completed
• Task 1 – Field environment: Build a 2D grid for a potato field. Mark safe travelling cells, potato rows, crop-protection
regions, obstacles, the robot's start position and its destination. Use a clear visualisation.
• Task 2 – Problem formulation: Specify the initial state, available actions, transition model, goal test and path-cost function.
State how the robot is allowed to move.
• Task 3 – Search algorithms: Implement Breadth-First Search (BFS), Depth-First Search (DFS), Greedy Best-First Search
and A* Search. Define and explain the heuristic used by the informed algorithms.
• Task 4 – Crop-safe planning: Ensure that the robot does not enter obstacle cells or crop-protection cells. Introduce a
suitable cost or penalty for routes that pass too close to protected crop regions, so safer alternatives are preferred where
available.
• Task 5 – Obstacle detection and replanning: Start with a map containing at least one obstacle unknown to the robot.
During the simulated journey, let the robot detect it, update its known map and use A* to calculate a new route if the current
route is blocked. Detection can be simulated in Python; hardware or actual sensors are not required.
• Task 6 – Performance evaluation: Compare algorithms using path length, number of expanded nodes, execution time and
whether the destination was reached. For the online-obstacle experiment, also report the number of replanning operations.
Present the results in a table.

4. Expected Program Output
• A visual display of the field grid, crop rows, protected regions and obstacles.
• The robot's starting position and destination.
• The path generated by each implemented search algorithm.
• A demonstration of an initially unknown obstacle being detected and the route being replanned.
• A comparison table summarising the performance of the algorithms.
